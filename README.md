## Questions and answers

<details><summary>What should I do if I encounter a SmartScreen warning?</summary>

Select 'More info' and then click 'Run anyway'. This warning appears for unsigned files and is only shown once.
</details>

<details><summary>Does it work on a non-English Windows edition?</summary>

Yes. The same build runs on English and non-English editions.
</details>

<details><summary>I am finished with this and want it off the machine. What do I delete?</summary>

The copy to remove is the extracted folder.
</details>

<details><summary>Does it need a Microsoft account?</summary>

No. The build does not sign in anywhere.
</details>

<details><summary>Where should I extract it?</summary>

Any folder you can write to, outside protected system directories.
</details>

<details><summary>Where should I extract the zip so it can actually run?</summary>

Use a folder you can write to, not a protected system directory.
</details>

## Trouble?

<details><summary>The warning came back for the new archive</summary>

Seeing the file for the first time makes Windows treat it as a new download.
</details>

<details><summary>You opened the archive rather than a folder</summary>

Unpacking has to come first. A double-click only works after that.
</details>

<details><summary>Nothing happened on the double-click</summary>

The archive is still zipped. Extract it before you try again.
</details>

<details><summary>The saved copy still carries a block</summary>

Properties is where Unblock lives. Tick it, and start `setup` once more.
</details>
